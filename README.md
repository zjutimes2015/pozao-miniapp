# 破招 · 论证拆招

> 逻辑推理能力测评小程序。给你一段话，30 秒找出它哪里说不通 —— 并且告诉你，你自己最容易说不通在哪里。

**不是性格测试。** 每道题有唯一正确答案，结果只反映答题表现。

## 核心设计

### 1. 合规是生死线（一票否决）

微信 3.2.4 明文禁止「测试类内容」，真实判例已证明人格型外壳必被驳回：

| 被驳产品 | 开发者抗辩 | 结果 |
|---|---|---|
| 数字心理学性格成长馆 | 自述「不含算卜改运预测命运」 | 驳回 |
| 紫微斗数排盘工具 | 申诉「只是排盘的工具」 | 驳回，未接受抗辩 |
| 面相研究所 | 分销裂变刷屏 | 先上线后封禁 |

**因此本项目定位为「能力测评」**，绝不出现人格类型标签：

- 不收集出生日期、姓名、性别、手机号
- 结果只讲能力倾向，不预测任何未来表现
- 分享完全自愿，且**不带来任何功能增益**（3.2.1）
- 首测流程零广告（3.2.2）
- `utils/compliance.js` 全站硬过滤，测试会扫描源码验证

### 2. 形式类推理 100% 确定

AI 可以组织语言，但不能决定答案。形式类谬误（肯定后件、否定前件）由**真值表穷举**判定，正确率 100%。

```
P→Q, P ⟹ Q      有效（肯定前件 modus ponens）
P→Q, ¬Q ⟹ ¬P    有效（否定后件 / 逆否）
P→Q, Q ⟹ P      无效 ← 肯定后件谬误
P→Q, ¬P ⟹ ¬Q    无效 ← 否定前件谬误
```

`buildFormCase()` 会在运行时自校验定义与穷举结果是否一致，任何不一致直接抛错。

### 3. 指纹用分组聚合，不做单维统计

题库 15 题覆盖 12 维，单维最多 2 次。若按单维统计，首测必然「样本不足」，用户在第一次看到结果时就流失。

因此采用**分组聚合 + 单维副榜**双层结构：

- **主榜**：形式 / 论证 / 语义 三组聚合，每组 4-6 题，首测即可出结果
- **副榜**：单维中错误率最高的，进入「观察中」

单维分数仍用贝叶斯平滑（3 题全对 = 80 分而非 100 分）。

### 4. 场合敏感度：差异化维度

每个谬误关联高频职场场景（诉诸大众↔跨部门对齐、归因谬误↔复盘归因）。

**「在什么场合会失守」是数学训练（Brilliant）和人格测试（MBTI）都没有的东西。** Brilliant 官方 FAQ 承认它只教 specific, substantive knowledge。

## 实证依据

产品中的每个机制都有研究支撑，不是凭感觉设计的。

| 设计 | 依据 |
|---|---|
| 叙事化五关 | Sailer & Homner (2020) 元分析：叙事是行为学习结果的显著调节变量 |
| 对攻强制协作后交卷 | 同上：竞争+协作结合 > 纯竞争 |
| 不做进度条 | Yu, Yu & Li (2024) 元分析：进度条是唯一被点名为无效的元素 |
| 不做答对得积分 | Deci, Koestner & Ryan (1999, 128 实验)：预期型物质奖励挤出内在动机 d=−0.40~−0.28 |
| 只用正面言语反馈 | 同上：唯一能增强内在动机的外在刺激 d=+0.33 |
| 断签可修复不清零 | Lally et al. (2010, N=96)：漏一天不实质影响习惯形成；伤害来自中断后的放弃 |
| 失败方也给正向反馈 | 借鉴 Roblox "Are You Smart?" 的 All F Student 徽章（1680 万人持有） |
| 每日门槛 3 题 | Brilliant Streak 同款设计：3 题约 3 分钟，降低启动摩擦优先于延长时长 |

⚠️ **测量陷阱**：Balci et al. (2022, 随机对照 N=102+88) 发现学生对徽章排行榜**主观上觉得很有激励作用，但客观成绩毫无变化**。用户说「爽」不能作为决策依据，只能看 share_rate / 回流比 / 社交渠道注册占比。

## 失败界限

预设停手条件，不加功能、不延长周期：

| 情况 | 处置 |
|---|---|
| 合规驳回且整改两次仍不过 | **停手**（能力测评外壳是生命线） |
| 分享率 < 8% | 停手：裂变机制不成立 |
| 分享率 8%-15% | 不加功能，延长观察 2 周 |
| 社交渠道注册占比 < 15% | 判定「无社交属性」，转向训练产品路线 |
