## 0. 一句话定位

**给你一段话，30 秒找出它哪里说不通 —— 并且告诉你，你自己最容易说不通在哪里。**

不是性格测试。是**能力测评**。有客观对错，有唯一正确答案。

## 1. 为什么从 v1.0 转向游戏版

### 1.1 转向的理由

| 维度 | v1.0（能力刻度闭环） | v2.0（游戏版） |
|---|---|---|
| 首次可见价值 | 5 分钟做 20 题才出刻度 | **30 秒一关，立刻有结果** |

| 服务器风险 | 低 | **高（SBTI 死因之一）** |

- **12 维能力模型**（§4）
- **形式类程序化生成 + 真值表验证**的防幻觉架构
- **AI 苏格拉底陪练**（作为留存层，不作为裂变层）
- 三级降级链

## 2. 合规：这一节是全文档最高优先级

### 2.1 微信三条明文红线（产品设计前提，不是事后补救）

| 条款 | 原文要点 | 本产品做法 |
|---|---|---|
| **3.2.4** | 「小程序的页面内容中，不能存在**测试类内容**；示例：算命，抽签，星座运势等」 | **定位"能力测评"，绝不出现人格类型标签**；不收集出生日期；结果只讲能力倾向不讲命运 |
| **3.2.1** | 诱导分享：「要求用户分享、添加、关注或下载后才可操作的程序」「通过利益诱惑诱导用户分享」 | **分享完全自愿；分享不解锁任何内容；单人体验100% 完整** |

| **3.1.8** | 「小程序功能的使用，无需以关注或使用其他号为条件」 | 不做关注解锁 |

### 2.2 真实驳回案例（必须规避）

| 被驳产品 | 开发者抗辩 | 结果 |

| 紫微斗数排盘工具 | 「没有算命付费，只是排盘的工具」 | **驳回，未接受抗辩** |

### 2.4 提审话术模板（照抄，参照案例3 的整改标准）

> 本产品定位为**逻辑推理能力测评工具**。
> 1. 不收集用户出生日期、姓名、性别等任何个人信息
> 2. 测试结果为**客观答题表现**，每道题有唯一正确答案

> 4. 全站无任何人格类型标签，无任何玄学元素
> 5. 分享为用户自愿行为，**分享不解锁任何功能**，不设分享奖励
> 6. 首测流程零广告

## 3. 核心玩法：五关叙事拆招

### 3.1 题目形态（不是选择题）

**核心动作：把一段话拖成「前提 / 结论」，标出推理断点。**

```
【第1 关】老板说这句话对不对？

  "我们去年招了 5 个销售，业绩最好的那个，
   毕业院校都是 985。所以招 985 的学生，
   业绩一定不会差。"

  把卡片拖到正确位置：
  ┌──────────┐      ┌──────────┐      ┌──────────┐
  │ 前提     │  →   │ 推理     │  →   │ 结论     │
  │ 业绩最好 │      │ 他都毕业于│      │ 招985    │
  │ 的是985  │      │ 985，所以 │      │ 业绩不差 │
  └──────────┘      └──────────┘      └──────────┘

  ⚠️ 这里有个断点，你指出来
  [ 他⟶所有人 ]← 用户在这里点一下
```

### 3.2 五关结构（叙事化，约 3-4 分钟）

| 关 | 场景 | 训练的谬误 | 难度 |
|---|---|---|---|
| 1 | 老板的季度总结 | 诉诸大众 | 热身 |
| 2 | 同事的方案汇报 | 合成谬误 | 入门 |
| 3 | 销售的客户话术 | 滑坡谬误 | 进阶 |
| 4 | 老板的危机决策 | 归谬 | 挑战 |
| 5 | 行业新闻报道 | 以偏概全 + 归因谬误 | 综合 |

> **叙事化的实证依据**：Sailer & Homner (2020) 元分析（认知 N=1686/ 动机 N=2246 / 行为 N=951）发现「**游戏叙事是行为学习结果的显著调节变量**」——叙事元素对"用户实际做了什么"影响最大。且该元分析发现「**竞争+协作结合**」比纯竞争有效。

### 3.3 零门槛铁律（SBTI 的教训）

| 项 | 要求 | 依据 |
|---|---|---|
| 注册 | **不要求** | SBTI 零门槛引爆的核心理由 |
| 手机号 | **不收集** | SBTI 山寨被网警预警的诱因之一 |
| 首次可见结果 | **≤ 90 秒**（第 1 关结束即出分） | 5 分钟太长，会流失在首关前 |
| 单人完整体验 | **100%**（无论是否分享） | 3.2.1 合规前提 |

## 4. 论证指纹：产品的核心资产

### 4.1 双重输出结构（这是设计的核心）

**不做"你是什么型"，做「你强在哪、弱在哪、弱在什么场合」。**

```
你的论证指纹
═══════════════════════════

最容易被你用出来的破绽
  1. 诉诸大众    68%   "大家都这么做，所以没问题"
  2. 滑坡谬误    54%   "这一步不行，后面全崩"
  3. 合成谬误    41%

你最擅长的抓漏洞
  1. 归谬       91%
  2. 偷换概念   84%
  3. 肯定后件   72%

你在这些场合最容易失守
  ⚠️ 高压会议  ·  当众表态时
  ⚠️ 反驳上级  ·  被质疑时
  ⚠️ 快速决策  ·  信息不全时
```

### 4.2 为什么这个结构合规且有效

| 维度 | 论证 | |
|---|---|---|
| 合规 | 不含人格类型、不含命运预测、不采集生日 | 3.2.4 射程之外 |
| 学术 | 能力测试误差可通过增加指标数降低；人格测试存在无法消除的误差下限 | 自陈式测量误差由用户自我知识决定 |
| 信任 | 每道题有唯一正确答案，可被外部验证 | 区别于巴纳姆效应（MBTI 契合度平均 4.26/5 但重测39%-76% 变类型） |
| 分享 | 「我最容易被骗的是诉诸大众68%」比「你是ENFP」更有具体感与自嘲感 | 更像真实数据而非星座 |

### 4.3 指纹算法

```
易犯率(fall_rate)  = 被诱导选中该谬误的次数 / 该谬误出现总次数
会抓率(catch_rate) = 正确识别的次数 / 该谬误出现总次数
场合敏感度(situ_sensitivity) = 该谬误在特定场景下的表现显著低于总体时的加权值
```

- 每维最少 **8 道题**才计入指纹（不足则显示"样本不足"）
- 指纹需至少 **3 关全通**才生成完整版，否则只显示首关结果
- **贝叶斯平滑**：`score = (正确数 + 1) / (总次数 + 2) × 100`

### 4.4 "场合敏感度"的实现（这是差异化点）

每个谬误关联一个高频职场场景：

| 谬误 | 关联场景 |
|---|---|
| 诉诸大众 | 跨部门对齐 |
| 合成谬误 | 评估供应商 |
| 滑坡 | 合规风险判断 |
| 归谬 | 谈判反驳 |
| 以偏概全 | 竞品分析 |
| 归因谬误 | 复盘归因 |
| 偷换概念 | 需求变更 |
| 肯定后件 | 数据看板解读 |

> **为什么这个设计有价值**：Brilliant 明确不做批判性思维（官方 FAQ 承认"teaches specific, substantive knowledge"），只做数学。**"在什么场合会失守"是数学训练和 MBTI 都没有的东西。**

## 5. 裂变设计

### 5.1 结果卡（分享物的设计）

**三张卡，全部为静态图，可直接发朋友圈/群**

| 卡片 | 内容 | 设计意图 |
|---|---|---|
| 卡1 · 指纹| 易犯 Top3 + 会抓 Top3 | 核心可炫耀性 |
| 卡2 · 场合 | 「你最易在高压会议失守」| 制造自嘲与话题 |
| 卡3 · 对攻邀请 | 「敢不敢来拆同一段话」 | **拉新钩子** |

**卡片要素**（借鉴 16Personalities 真实结构）：
- 一个**短代码**（如 `PZ-7A3F`）作为社交标签，好记、可口头传播
- 每个维度用**百分比**呈现，制造精确感
- 明确显示"共X人测过"（样本真实，禁止造假）

### 5.2 同题对攻（拉新主机制）

```
你发了卡→  好友扫码 → 同拆一段话
         → 谁的漏洞找得更全谁赢
         → 双方都看到对方的答题路径
```

**关键设计：协作 + 竞争结合**（Sailer & Homner 2020 的实证结论）

- 双方答案**合并后才能交卷**（强制协作）
- 合并后找全漏洞的一方胜出（竞争）
- **失败方也获得"被你抓住了"的反馈**（借鉴 Roblox "Are You Smart?"的 All F Student 徽章，1680 万人持有）

### 5.3 小圈层排行榜（用户已选择）

| 设计 | 具体 | 依据 |
|---|---|---|
| 规模 | **只邀请的人 + 陌生人混编 30 人** | Brilliant Leagues = 30 人/联赛。避免全球榜单压力 |
| 周期 | 每周重置 | 同 Brilliant |
| 段位 | **6 段，用破招术语命名**：初识 → 拆解 → 反驳 → 追问 → 洞察 → 无遗 | 同Brilliant 元素周期表思路但改用领域语言 |
| **不做** | 全球排行榜、不做总榜 | 证据：Balci et al. (2022) 随机对照（N=102 + N=88）发现徽章与排行榜**对学业表现无显著影响** |

> **必须承认的学术争议**：Hanus & Fox (2015) 发现含排行榜+徽章+竞争机制的课程，学生动机、满意度、赋权感**均低于**非游戏化组。而 Cameron & Pierce (1994) 的挤出结论被 Eisenberger & Cameron (1996) 批评为"挤出基本是神话"，Deci 等用 128 项研究的新元分析反驳。**这个争论至今未决**，故本产品采用"小圈层 + 有协作"的折中，而非纯竞争。

### 5.4 分享的合规红线

|❌ 绝对不做 | 条款 |
|---|---|
| 分享后解锁完整报告 | 3.2.1 |
| 分享后获得额外关卡 | 3.2.1 |
| 分享得积分 / 抽奖机会 | 3.2.1 |
| 未分享时功能残缺 | 3.2.1 |

| ✅ 可以做 | 说明 |
|---|---|
| 结果卡自带小程序码（用户自愿保存转发） | 「实用心理测试大全」被封的是"通过朋友圈识别小程序码进入"的**平台入口识别能力**，不是卡片本身 |
| 结果页显眼位置放「生成卡片」按钮 | 用户主动行为 |
| 对攻邀请（自愿发起） | 不设奖励、不强制 |

> **风险预案**：「实用心理测试大全」案例中，微信封禁朋友圈识别入口后PV 急速下降。**因此对攻邀请必须同时支持「复制短代码」与「保存卡片」两条路径**，不依赖微信的入口识别能力。

### 5.5 服务器容量（SBTI 死因 #1）

| 项 | 要求 | 依据 |
|---|---|---|
| 上线前压测 | 峰值 **10,000 QPS** | SBTI"全国几千万人挤爆服务器"，服务器 404 |
| 架构 | 题库全量本地化（小程序包内），答题**不依赖服务端** | 避免瞬时崩塌 |
| 结果计算 | 本地算法，60 秒内出结果 | 只在保存/对攻时请求云端 |
| 降级 | 云端不可用时本地完整可玩 | 沿用三级降级链 |
| 云函数限流 | 单用户对攻请求 **1 次/3 秒** | 防刷 |

## 6. 训练层（承接留下的人）

**裂变层留住的是注意力，训练层留住的是能力。留下的人（约 15-20%）进入这里。**

| 机制 | 设计 | 证据 |
|---|---|---|
| **12 维刻度** | 永久免费，含历史曲线 | 首个方案，已确认 |
| **AI 苏格拉底陪练** | 免费无限，¥0.0064/次 | 成本已核算 |
| **周复测** | 嵌入日常，3 题 | Brilliant 机制 |
| **每日门槛** | **3 题或 1 关，约 3 分钟** | Brilliant Streak 门槛对齐 |
| **断签设计** | **不做"漏一天清零"，做"可修复"** | Lally et al. (2010, N=96)：「Missing one opportunity to perform the behaviour did not materially affect the habit formation process」；伤害来自中断后的放弃（违反戒断效应 Marlatt），非中断本身 |
| **不做进度条** | — | Yu, Yu & Li (2024, *Education and Information Technologies* 29(4)) 元分析 27 项实验：**唯一被点名为无效的游戏化元素是进度条** |
| **奖励设计** | **随机掉落/里程碑纪念，不做"答对即得10 积分"** | Deci, Koestner & Ryan (1999, *Psychological Bulletin* 125(6), 128 项实验)：参与挂钩 d=−0.40、完成挂钩 d=−0.36、表现挂钩 d=−0.28；**只有"预期型"奖励产生挤出**，非预期奖励 d≈−0.01。且 Cerasoli et al. (2014, k=183, N=212,468) 证明奖励与表现**弱挂钩/间接挂钩时，内在动机的预测效度反而上升** |
| 唯一可用的外在刺激 | **正面言语反馈**（同一元分析：d=+0.33） | "你抓到了隐藏前提，这题很多人会漏看" |

> **一条重要的产品哲学**：Brilliant 在 2025年 12 月的 arXiv 论文（arXiv:2512.08551，125 人 best-worst scaling 问卷）中得出同样结论——用户最看重的不是积分金币，而是**进度可视化 + 即时反馈**。高管原话："The real question is not 'How do we make learning addictive?' It's: **'How do we make thinking rewarding?'**"

## 7. 题库设计

### 7.1 题量

| 用途 | 数量 | 说明 |
|---|---|---|
| 叙事五关（首测） | 5 关 × 3 题 = **15 题** | 3 分钟内完成 |
| 对攻题库 | **30 题** | 多人可重复对战不同题 |
| 每周轮换题 | **20 题** | 保证"每日内容不同"，避免用户批评"就是十种题的无聊重复" |
| **合计** | **65 题** | 形式类程序化 + 语义类 AI 双模型 |

> **V1 不做 90 题**。相比 v1.0 缩减 28%，因为游戏版的核心资产是"题目的结构与唯一答案性"，不是数量。

### 7.2 生产管线（沿用 v1.0 架构）

```
Generator（DeepSeek）
  ↓ 题目 + 唯一答案 + 推理链 ground_truth + 干扰项设计
Verifier（第二模型独立复核）
  ↓ ① 答案是否唯一 ② 前提是否充分 ③ 干扰项是否有争议
分歧仲裁 → 人工队列
  ↓
人工抽检 10%（错误率 >5% 则该维度全量重生成）
  ↓
回归验证集 100 题（人工精标，一致率 <90% 不得发布）
```

- 单题成本 ¥0.01，65 题约 ¥0.65
- **形式类题目（肯定后件/否定前件/合成/归谬）程序化生成 + 真值表验证，正确率 100%**

## 9. 不做什么（Non-Goals）

| 不做 | 原因 |
|---|---|
| 人格类型标签（"你是ENFP"式） | 3.2.4 红线 + 学术上重测 39%-76% 变类型 |
| 收集出生日期 / 姓名 | 切断与命理的关联 |
| 分享解锁任何内容 | 3.2.1 |
| 关注公众号解锁 | 3.1.8 |
| 首测流程放广告 | 3.2.2（广告占比 >50% 即驳回） |
| 全球排行榜 | Balci et al. 2022 随机对照显示排行榜对表现零影响 |
| 进度条 | Yu, Yu & Li 2024 元分析点名的唯一无效元素 |
| "答对即得 N 积分"的确定性奖励 | Deci et al. 1999：预期型有形奖励挤出效应 d=−0.28~−0.40 |
| 断签清零式严苛 streak | Lally et al. 2010：漏一天几乎无伤害，清零才制造伤害 |
| 付费解锁报告 | 实测付费转化仅 2.16%，且 iOS 禁虚拟支付；V1 先验证裂变 |
| 难度递进的闯关关卡制 | 与"能力测评"定位冲突，会把产品拉回游戏化而非训练化 |

## 10. 验收标准

### ① 合规验收（**一票否决**）

- 类目「教育 - 素质教育」审核通过
- 禁用词全站命中数 = **0**（含代码注释与配置项）
- iOS 虚拟支付相关代码/文案 = **0**
- **未分享时功能完整度= 100%**（逐项自查）
- 隐私政策 URL 已填入后台
- 商标已提交注册（SBTI 死因之一）

### ② 内容验收

- 形式类题目真值表验证正确率 **100%**
- 语义类双模型一致率 ≥ **90%**
- 人工抽检 10%，错误率 ≤ **5%**
- 叙事五关综合正确率落在 **45% - 60%**
- 每题有唯一正确答案，干扰项无争议

### ③ 体验验收

- 首关完成 ≤ **90 秒**
- 完整五关≤ **4 分钟**
- 答题 → 反馈渲染 ≤ **1.5 秒**（纯本地，必须更快）
- 指纹结果生成 ≤ **3 秒**
- 对攻匹配 ≤ **5 秒**
- **服务器峰值 10,000 QPS 不崩**（压测报告）

### ④ 裂变验收（这是游戏版的成败线）

| 指标 | 门槛 | 依据 |
|---|---|---|
| 分享率 | ≥ **15%** | 从业者自述数据：教育类分享率约 14% 为平均，30%+ 为优秀 |
| 分享回流比 | ≥ **10%** | 从业者自述：游戏/社交类回流约 10%，工具类超 30% |
| 完成五关率 | ≥ **70%** | 保留精简流程（4 分钟内） |
| 对攻发起率 | ≥ **8%** | 裂变层→训练层的转化入口 |
| 社交渠道注册占比 | ≥ **30%** | 微信官方：社交玩法做得好的游戏该比例为 30%-50% |

### ⑤ 留存验收（承接留下的人）

| 指标 | 门槛 |
|---|---|
| 完成指纹后 7 日留存 | ≥ **12%** |
| 进入训练层比例 | ≥ **15%** |
| 训练层 D7 留存 | ≥ **20%**（进入训练层的人质量更高） |

### ⑥ 失败界限（预设停手条件）

> **任一项不达标，不加功能、不延长周期。**

| 情况 | 处置 |
|---|---|
| 合规驳回且整改两次仍不过 | **停手**（能力测评外壳是本产品的生命线，失守则无产品） |
| 分享率< 8% | 停手：裂变机制不成立 |
| 分享率 8%-15% | 不加功能，但可延长观察 2 周 |
| 社交渠道注册占比 < 15% | 判定为"无社交属性"，转向原 v1.0 能力刻度路线 |

## 附录 A：五关叙事题示例（游戏语气基准）

**第 1 关 · 老板的季度总结**
> "这个季度我们把用户留存做上去了，整体增长 40%。北京、上海、广州的核心城市都是40% 左右，说明我们的增长策略是有效的，可以复制到下沉市场。"

用户需指出：⚠️「你拿到的是**总体** 40%，但结论依赖的是**三个核心城市**的数字。总体增长里有多少来自核心城市以外？"

**第 3 关 · 销售的客户话术**
> "行业里头部几家都在做智能客服了，我们不做就 definitely 会被落下。而且我们已经有 2000 万用户基础，上线之后肯定能用起来。"

用户需指出两个断点：⚠️ 滑坡（"不上→被落下"是未论证的后果链） ⚠️ 肯定后件（"有用户基础 → 肯定能用起来"）

**第 5 关 · 行业新闻报道**
> "某独角兽公司宣布完成新一轮融资，估值超过 100 亿。此前该行业已有 3 家公司成功上市，说明整个赛道的商业模式已经跑通。"

用户需指出：⚠️ 以偏概全（3 家成功上市不能证明"整个赛道已跑通"，也未统计失败数量）

> **语气标准**：冷静、具体、指出断点时说清"为什么这一步不成立"，不说教、不灌鸡汤、不嘲讽用户。
