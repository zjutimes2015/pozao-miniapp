## 历史版本

### [SPEC v1 · 能力刻度闭环](SPEC-v1-能力刻度闭环.md)（已被 v2 取代）

纯训练产品路线：测评 → 处方 → 复测，不做裂变。

**为什么转向 v2**：v1 首次可见价值需 5 分钟做完 20 题，传播能力弱；
v2 把首次可见价值压到 30 秒，并增加同题对攻作为拉新钩子。

v1 的核心资产**全部保留**：12 维能力模型、形式类程序化生成、AI 苏格拉底陪练、三级降级链。

## 关键决策速查

想快速理解"为什么这样设计"，看这张表：

| 决策 | 依据 |
|---|---|
| 定位"能力测评"而非人格测试 | 微信 3.2.4 + 数字心理学性格成长馆、紫微斗数排盘两起驳回判例 |
| 形式类用真值表穷举 | AI 只能组织语言，不能决定答案。Brilliant 的 Koji 同此思路 |
| 指纹用分组聚合 | 15 题 / 12 维，单维最多 2 次，逐维统计会永远"样本不足" |
| 不做进度条 | Yu, Yu & Li (2024) 元分析：唯一被点名为无效的元素 |
| 不用答对得积分 | Deci et al. (1999, 128 实验)：预期型物质奖励挤出动机 d=−0.40 |
| 只用正面言语反馈 | 同上：唯一正向外在刺激 d=+0.33 |
| 断签可修复不清零 | Lally et al. (2010, N=96)：漏一天不实质影响习惯形成 |
| 不做全球排行榜 | Balci et al. (2022, 随机对照 N=190)：对学业表现零效果 |
| 对攻强制协作后交卷 | Sailer & Homner (2020)：竞争+协作结合 > 纯竞争 |
| 失败方也给正向反馈 | 借鉴 Roblox "Are You Smart?" 的 All F Student 徽章（1680 万人持有） |
| 匿名标识而非 openid | 产品定位是零采集，openid 需在隐私政策声明 |
| 分享不做任何奖励 | 微信 3.2.1 明文禁止利益诱惑诱导分享 |
